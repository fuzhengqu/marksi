# MarkSI 0.66

MarkSI 0.66（versionCode `66`）发布，为 Mermaid 图表加入源码复制。

## 亮点

- 实时预览的 Mermaid 卡片新增顶部栏和**复制源码**按钮。
- 阅读视图的 Mermaid 源码折叠区也提供复制按钮，标题随界面语言本地化。
- 复制内容为围栏内的原始 Mermaid 源码，不包含围栏标记。
- 复制成功后短暂显示**已复制**；不会揭示源码、展开阅读视图面板或改写文档。
- 导出的 HTML 保持静态，打印隐藏复制按钮，PNG 导出过滤复制控件。

## 下载

- **推荐**：`MarkSI_0.66_x64-setup.exe`，单个安装器内置英文、简体中文和繁体中文界面，并按系统语言选择。
- **企业部署**：`MarkSI_0.66_x64.msi`，安装界面为 `en-US`，应用仍包含三种界面语言。
- **Linux**：`.deb`、`.rpm`、`.AppImage` 和 `.flatpak`。
- 所有安装包均未签名；Windows 可能显示 SmartScreen 提示。

## 校验

Release 附带合并的 `SHA256SUMS.txt` 和 Windows/Linux 两份第三方声明。请先校验下载文件的 SHA-256，再运行安装包。

## English

MarkSI 0.66 (versionCode `66`) adds Mermaid source copying. The live-preview
diagram card and the reading-view source disclosure expose a localized
copy-source action that writes the raw fence content without revealing the
source, expanding the disclosure, or rewriting the document.

The NSIS `setup.exe` is the recommended installer; the MSI uses an `en-US`
installer UI. Linux packages include deb, rpm, AppImage, and Flatpak. All
installers are unsigned; Windows may show a SmartScreen warning. Verify the
attached `SHA256SUMS.txt` before installation.
