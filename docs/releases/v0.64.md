# MarkSI 0.64

MarkSI 0.64（versionCode `64`）发布，把代码复制扩展到阅读视图。

## 亮点

- 阅读视图的代码块语言栏新增**复制代码**按钮。
- 复制高亮后的纯代码文本，不包含围栏标记；空代码块按钮自动禁用。
- 复制成功后短暂显示**已复制**，并同步更新无障碍标签。
- 复制控件只存在于阅读视图：导出的 HTML 保持静态，PNG 图片导出会过滤按钮，打印时按钮隐藏。
- 代码块复制与阅读视图的滚动、链接和图片交互互不干扰。

## 下载

- **推荐**：`MarkSI_0.64_x64-setup.exe`，单个安装器内置英文、简体中文和繁体中文界面，并按系统语言选择。
- **企业部署**：`MarkSI_0.64_x64.msi`，安装界面为 `en-US`，应用仍包含三种界面语言。
- **Linux**：`.deb`、`.rpm`、`.AppImage` 和 `.flatpak`。
- 所有安装包均未签名；Windows 可能显示 SmartScreen 提示。

## 校验

Release 附带合并的 `SHA256SUMS.txt` 和 Windows/Linux 两份第三方声明。请先校验下载文件的 SHA-256，再运行安装包。

## English

MarkSI 0.64 (versionCode `64`) adds code-copy buttons to fenced code blocks in
the reading view. The copied text excludes fence markers, empty blocks are
disabled, and the button briefly shows a localized copied state.

The control is preview-only: exported HTML stays static, PNG capture filters the
button, and print hides it. The NSIS `setup.exe` is the recommended installer;
the MSI uses an `en-US` installer UI. Linux packages include deb, rpm, AppImage,
and Flatpak. All installers are unsigned; Windows may show a SmartScreen warning.
Verify the attached `SHA256SUMS.txt` before installation.
