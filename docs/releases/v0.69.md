# MarkSI 0.69

MarkSI 0.69（versionCode `69`）发布，加入 GitHub 更新检查与安装器品牌化。

## 亮点

- Help 菜单新增**检查更新**，从 GitHub Releases 获取最新版本。
- 更新对话框显示当前版本、最新版本、发布日期和更新说明；有新版本时可直接前往 GitHub 下载。
- 网络错误、超时和 GitHub 限流会显示可重试的错误状态，不会影响编辑。
- Preferences > Updates 新增**自动检查更新**开关，默认关闭。开启后最多每 24 小时检查一次，只在发现新版本时显示非模态提醒，不弹模态窗、不自动安装。
- 用户点过“稍后”后，同一版本不会再反复提醒。
- 关于对话框新增 **GitHub 项目**和**报告问题**链接。
- Windows NSIS 安装器使用品牌顶部图、侧边图、安装/卸载图标；MSI 使用品牌横幅和对话框图。
- 安装器补充 publisher、homepage 和 copyright 元数据；`LICENSE` 文件保持不变。
- 更新检查是唯一的联网路径，且只在用户手动点击或明确开启自动检查时发生，不发送文档内容。

## 下载

- **推荐**：`MarkSI_0.69_x64-setup.exe`，单个安装器内置英文、简体中文和繁体中文界面，并按系统语言选择。
- **企业部署**：`MarkSI_0.69_x64.msi`，安装界面为 `en-US`，应用仍包含三种界面语言。
- **Linux**：`.deb`、`.rpm`、`.AppImage` 和 `.flatpak`。
- 所有安装包均未签名；Windows 可能显示 SmartScreen 提示。

## 校验

Release 附带合并的 `SHA256SUMS.txt` 和 Windows/Linux 两份第三方声明。请先校验下载文件的 SHA-256，再运行安装包。

## English

MarkSI 0.69 (versionCode `69`) adds GitHub update checks and installer branding.

Help > Check for updates queries the latest GitHub Release and shows the
current/latest versions, publication date, release notes, and a download
action. Network failures, timeouts, and GitHub rate limits produce a retryable
error state without affecting editing.

Preferences > Updates adds an automatic update check that is off by default.
When enabled it checks at most once every 24 hours and shows a non-modal notice
only when a newer release exists. It never opens a modal at startup or installs
silently. Dismissing a version stops repeated notices for that version.

About now links to the GitHub project and issue tracker. Both Windows installers
use branded header/sidebar or banner/dialog art, installer/uninstaller icons,
and publisher/homepage/copyright metadata; the MIT `LICENSE` file is unchanged.
Update checks are the only network path and never send document content.

The NSIS `setup.exe` is the recommended installer; the MSI uses an `en-US`
installer UI. Linux packages include deb, rpm, AppImage, and Flatpak. All
installers are unsigned; Windows may show a SmartScreen warning. Verify the
attached `SHA256SUMS.txt` before installation.
