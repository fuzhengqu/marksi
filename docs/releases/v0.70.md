# MarkSI 0.70

MarkSI 0.70（versionCode `70`）发布，重做 Windows 安装器品牌图和升级路径。

## 亮点

- NSIS 与 MSI 统一为 per-machine 安装，默认路径为 `C:\Program Files\MarkSI`，安装/卸载需要管理员权限。
- NSIS 安装器会在安装前检测并静默移除 0.69 的旧 per-user 安装，避免用户目录和 Program Files 各留一套。
- MSI 安装器包含 `NsisCleanup` 清理组件，接管 per-machine NSIS 安装时会移除 NSIS 的卸载项和 `uninstall.exe`，只保留一个“应用和功能”条目。
- 安装器图片整体重做：
  - NSIS 顶部图只保留产品标记，不再放文字；
  - NSIS 侧边图保留大字号 MarkSI，去掉容易发虚的小字；
  - MSI 顶部图把产品标记放到右侧，不再压住页面标题；
  - MSI 欢迎/完成页背景只在右上角放产品标记，不再与向导文字重叠；
  - 所有图片使用 4 倍尺寸绘制后下采样，减少锯齿。
- MSI 文件本身仍使用 Windows Installer 的系统图标；快捷方式和“应用和功能”使用 MarkSI 产品图标。若要让 `.msi` 文件本身显示产品图标，需要额外的 bootstrapper EXE。
- 安装器 license 页继续使用仓库中的 MIT `LICENSE`，未修改许可证文本。

## 升级说明

- 0.69 per-user `setup.exe` → 0.70 `setup.exe`：安装器自动迁移。
- 0.69 MSI → 0.70 MSI：WiX MajorUpgrade 升级。
- 0.70 per-machine NSIS ↔ MSI：NSIS 检测并卸载 MSI；MSI 清理 NSIS 残留。
- 0.69 per-user setup.exe → 0.70 MSI：建议先安装一次 0.70 `setup.exe` 完成迁移，或从“应用和功能”手动卸载旧版后再装 MSI。

## 下载

- **推荐**：`MarkSI_0.70_x64-setup.exe`，单个安装器内置英文、简体中文和繁体中文界面，并按系统语言选择。
- **企业部署**：`MarkSI_0.70_x64.msi`，安装界面为 `en-US`，应用仍包含三种界面语言。
- **Linux**：`.deb`、`.rpm`、`.AppImage` 和 `.flatpak`。
- 所有安装包均未签名；Windows 可能显示 SmartScreen 提示。

## 校验

Release 附带合并的 `SHA256SUMS.txt` 和 Windows/Linux 两份第三方声明。请先校验下载文件的 SHA-256，再运行安装包。

## English

MarkSI 0.70 (versionCode `70`) reworks Windows installer branding and upgrade
behavior.

NSIS and MSI now install per-machine under `C:\Program Files\MarkSI` and request
administrator rights. The NSIS installer silently removes a legacy 0.69
per-user installation before installing. The MSI includes an `NsisCleanup`
component that removes the per-machine NSIS uninstall entry and `uninstall.exe`
when it takes over, leaving one Apps & Features entry.

Installer art was rebuilt at 4× and downsampled: the NSIS header and WiX banner
contain only a product mark, the NSIS sidebar keeps a large wordmark without
small print, and the MSI welcome/finish background only has a corner mark so
wizard text is never covered.

The `.msi` file itself keeps the Windows Installer shell icon; shortcuts and
Apps & Features use the MarkSI product icon. A product-icon `.msi` would require
a bootstrapper EXE. The MIT `LICENSE` page is unchanged.

The NSIS `setup.exe` is the recommended installer; the MSI uses an `en-US`
installer UI. Linux packages include deb, rpm, AppImage, and Flatpak. All
installers are unsigned; Windows may show a SmartScreen warning. Verify the
attached `SHA256SUMS.txt` before installation.
