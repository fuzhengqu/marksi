# MarkSI 0.72

MarkSI 0.72（versionCode `72`）发布，修正 NSIS 安装/卸载页的 header 布局。

## 亮点

- 彻底移除 NSIS `headerImage` 和 `uninstallerHeaderImage` 配置，不再保留 150×57 图片槽位。
- 安装页与卸载页的标题、正文现在从左侧开始，占满整个 header 宽度。
- 卸载页左侧不再显示 MarkSI 图片 logo。
- 安装器/卸载器标题栏的小图标仍然保留，便于窗口识别。
- NSIS 欢迎页侧边图继续保留 logo 和大字号 MarkSI。
- MSI 保持 0.71 的方案：欢迎/完成页 logo 在左侧，banner 无 logo。

## 下载

- **推荐**：`MarkSI_0.72_x64-setup.exe`，单个安装器内置英文、简体中文和繁体中文界面，并按系统语言选择。
- **企业部署**：`MarkSI_0.72_x64.msi`，安装界面为 `en-US`，应用仍包含三种界面语言。
- **Linux**：`.deb`、`.rpm`、`.AppImage` 和 `.flatpak`。
- 所有安装包均未签名；Windows 可能显示 SmartScreen 提示。

## 校验

Release 附带合并的 `SHA256SUMS.txt` 和 Windows/Linux 两份第三方声明。请先校验下载文件的 SHA-256，再运行安装包。

## English

MarkSI 0.72 (versionCode `72`) fixes NSIS installer/uninstaller header layout.

The NSIS `headerImage` and `uninstallerHeaderImage` settings are removed
entirely, so there is no reserved 150×57 image slot. License/install/uninstall
titles and body text now use the full header width, and the uninstaller no
longer shows the left-side MarkSI image logo. The window/title-bar icons remain
for identification. The NSIS welcome-page sidebar keeps the logo and large
MarkSI wordmark. MSI keeps the 0.71 layout: left-side welcome logo and a
logo-free banner.

The NSIS `setup.exe` is the recommended installer; the MSI uses an `en-US`
installer UI. Linux packages include deb, rpm, AppImage, and Flatpak. All
installers are unsigned; Windows may show a SmartScreen warning. Verify the
attached `SHA256SUMS.txt` before installation.
