# MarkSI 0.71

MarkSI 0.71（versionCode `71`）发布，调整 Windows 安装器品牌图位置。

## 亮点

- MSI 欢迎/完成页的 logo 移到左侧空白区，右侧不再放 logo，安装向导文字不再被品牌图遮挡。
- MSI 许可证/安装页顶部 banner 去掉 logo，只保留底部强调线，页面标题保持清晰。
- NSIS 许可证/安装页顶部 header 去掉 logo，只保留底部强调线。
- NSIS 欢迎页侧边图继续保留 logo 和大字号 MarkSI。
- 所有图片继续使用 4 倍尺寸绘制后下采样。
- 安装范围、升级清理逻辑和 MIT 许可证页保持不变。

## 下载

- **推荐**：`MarkSI_0.71_x64-setup.exe`，单个安装器内置英文、简体中文和繁体中文界面，并按系统语言选择。
- **企业部署**：`MarkSI_0.71_x64.msi`，安装界面为 `en-US`，应用仍包含三种界面语言。
- **Linux**：`.deb`、`.rpm`、`.AppImage` 和 `.flatpak`。
- 所有安装包均未签名；Windows 可能显示 SmartScreen 提示。

## 校验

Release 附带合并的 `SHA256SUMS.txt` 和 Windows/Linux 两份第三方声明。请先校验下载文件的 SHA-256，再运行安装包。

## English

MarkSI 0.71 (versionCode `71`) adjusts Windows installer artwork.

The MSI welcome/finish page now places its single logo in the left blank area
and removes the right-side mark, so wizard text stays unobstructed. The MSI
banner and NSIS header now contain no logo, only the bottom accent rule. The
NSIS sidebar keeps the logo and large MarkSI wordmark. All artwork remains
rendered at 4× and downsampled.

The NSIS `setup.exe` is the recommended installer; the MSI uses an `en-US`
installer UI. Linux packages include deb, rpm, AppImage, and Flatpak. All
installers are unsigned; Windows may show a SmartScreen warning. Verify the
attached `SHA256SUMS.txt` before installation.
