# MarkSI 0.61

MarkSI 的首个 GitHub Release。`0.61` 是首个里程碑版本，versionCode 为 `61`。

## 亮点

- 实时预览支持 Mermaid 图表、GitHub 提示块、数学公式、表格、front matter、代码卡片和任务复选框。
- 实时预览支持无序列表项目符号与有序列表自动编号。
- 脚注引用显示为上标徽标，可跳转到定义。
- 链接支持 Ctrl+Click 打开外部链接、`#标题` 锚点跳转，以及打开本地 Markdown/文本文件。
- 保留本地优先、无账户、无遥测的设计；原始 HTML 不会作为活动内容执行。

## 下载

- **推荐**：`MarkSI_0.61_x64-setup.exe`，单个安装器内置英文、简体中文和繁体中文界面，并按系统语言选择。
- **企业部署**：`MarkSI_0.61_x64.msi`，安装界面为 `en-US`，应用仍包含三种界面语言。
- **Linux**：`.deb`、`.rpm`、`.AppImage` 和 `.flatpak`。
- 所有安装包均未签名；Windows 可能显示 SmartScreen 提示。

## 校验

Release 附带合并的 `SHA256SUMS.txt` 和 Windows/Linux 两份第三方声明。请先校验下载文件的 SHA-256，再运行安装包。

## English

The first MarkSI GitHub Release. Version `0.61`, versionCode `61`.

Highlights include Mermaid diagrams, GitHub alerts, math, tables, front matter,
task checkboxes, unordered bullets, ordered-list numbering, footnote badges, and
Ctrl+Click links for external URLs, heading anchors, and local Markdown/text
files.

The NSIS `setup.exe` is the recommended single installer and follows the system
language. The MSI is intended for enterprise deployment and uses an `en-US`
installer UI while shipping all three application languages. All installers are
unsigned; Windows may show a SmartScreen warning. Verify the attached
`SHA256SUMS.txt` before installation.
