# MarkSI 0.63

MarkSI 0.63（versionCode `63`）发布，为实时预览的代码块加入复制按钮。

## 亮点

- 实时预览的代码卡片在语言徽标旁新增**复制代码**按钮。
- 复制内容来自代码围栏的正文，不包含围栏标记。
- 空代码块按钮自动禁用；复制成功后短暂显示**已复制**。
- 复制不会揭示或改写 Markdown 源文件，点击语言徽标仍然只回源到围栏。
- 剪贴板写入通过独立模块隔离，便于自动化测试且不影响生产剪贴板。

## 下载

- **推荐**：`MarkSI_0.63_x64-setup.exe`，单个安装器内置英文、简体中文和繁体中文界面，并按系统语言选择。
- **企业部署**：`MarkSI_0.63_x64.msi`，安装界面为 `en-US`，应用仍包含三种界面语言。
- **Linux**：`.deb`、`.rpm`、`.AppImage` 和 `.flatpak`。
- 所有安装包均未签名；Windows 可能显示 SmartScreen 提示。

## 校验

Release 附带合并的 `SHA256SUMS.txt` 和 Windows/Linux 两份第三方声明。请先校验下载文件的 SHA-256，再运行安装包。

## English

MarkSI 0.63 (versionCode `63`) adds copy buttons to fenced code blocks in the
editable live preview. The copied text excludes fence markers, empty blocks are
disabled, and the button briefly shows a localized copied state. Copying never
reveals or rewrites the source.

The NSIS `setup.exe` is the recommended single installer and follows the system
language. The MSI uses an `en-US` installer UI while shipping all three
application languages. Linux packages include deb, rpm, AppImage, and Flatpak.
All installers are unsigned; Windows may show a SmartScreen warning. Verify the
attached `SHA256SUMS.txt` before installation.
