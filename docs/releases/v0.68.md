# MarkSI 0.68

MarkSI 0.68（versionCode `68`）发布，加入可选的原始 HTML 预览。

## 亮点

- 原始 HTML 默认仍然关闭，在预览、导出、打印和复制中按文本显示，永远不会执行。
- Preferences > Markdown 新增“渲染原始 HTML”开关。开启后，用户 HTML 会先经过严格白名单清洗，再进入现有渲染管线。
- 保留安全的标题、列表、表格、details、强调、代码和链接等结构标签。
- 移除脚本、样式、图片、表单、嵌入内容、class、id、内联样式和事件处理器。
- 链接只保留安全协议，并且仍然只在用户点击时打开。
- 应用自身生成的代码复制按钮、图片、表格、数学公式和 Mermaid 标记不受影响。
- 导出 HTML、富文本剪贴板和打印使用同一套清洗设置。

## 下载

- **推荐**：`MarkSI_0.68_x64-setup.exe`，单个安装器内置英文、简体中文和繁体中文界面，并按系统语言选择。
- **企业部署**：`MarkSI_0.68_x64.msi`，安装界面为 `en-US`，应用仍包含三种界面语言。
- **Linux**：`.deb`、`.rpm`、`.AppImage` 和 `.flatpak`。
- 所有安装包均未签名；Windows 可能显示 SmartScreen 提示。

## 校验

Release 附带合并的 `SHA256SUMS.txt` 和 Windows/Linux 两份第三方声明。请先校验下载文件的 SHA-256，再运行安装包。

## English

MarkSI 0.68 (versionCode `68`) adds opt-in raw HTML preview. Raw HTML remains
escaped and inert by default. When enabled in Preferences > Markdown, user HTML
passes a strict allowlist before the normal renderer: safe headings, lists,
tables, details, emphasis, code, and links remain, while scripts, styles,
images, forms, embedded content, classes, ids, inline styles, and event
handlers are removed. Links keep safe protocols and open only on activation.
App-generated code, image, table, math, and Mermaid markup is unaffected. HTML
export, rich clipboard copy, and print use the same setting.

The NSIS `setup.exe` is the recommended installer; the MSI uses an `en-US`
installer UI. Linux packages include deb, rpm, AppImage, and Flatpak. All
installers are unsigned; Windows may show a SmartScreen warning. Verify the
attached `SHA256SUMS.txt` before installation.
