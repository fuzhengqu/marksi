# MarkSI 0.62

MarkSI 0.62（versionCode `62`）发布，完善本地链接的标题片段跳转。

## 亮点

- 实时预览和阅读视图支持本地 Markdown/文本链接中的 `#标题` 片段。
- 链接目标解析和标题匹配均在本地完成，不发起网络请求。
- 保持 Markdown 源文件不变；原始 HTML 仍然不会被当作活动内容执行。
- 继续坚持本地优先、无账户、无遥测。

## 下载

- **推荐**：`MarkSI_0.62_x64-setup.exe`，单个安装器内置英文、简体中文和繁体中文界面，并按系统语言选择。
- **企业部署**：`MarkSI_0.62_x64.msi`，安装界面为 `en-US`，应用仍包含三种界面语言。
- **Linux**：`.deb`、`.rpm`、`.AppImage` 和 `.flatpak`。
- 所有安装包均未签名；Windows 可能显示 SmartScreen 提示。

## 校验

Release 附带合并的 `SHA256SUMS.txt` 和 Windows/Linux 两份第三方声明。请先校验下载文件的 SHA-256，再运行安装包。

## English

MarkSI 0.62 (versionCode `62`) adds heading-fragment navigation for local
Markdown and text links in both the editable live preview and the reading view.
Link resolution stays local, the Markdown source is not rewritten, and raw HTML
remains inert.

The NSIS `setup.exe` is the recommended single installer and follows the system
language. The MSI uses an `en-US` installer UI while shipping all three
application languages. Linux packages include deb, rpm, AppImage, and Flatpak.
All installers are unsigned; Windows may show a SmartScreen warning. Verify the
attached `SHA256SUMS.txt` before installation.
