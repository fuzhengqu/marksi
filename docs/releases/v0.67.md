# MarkSI 0.67

MarkSI 0.67（versionCode `67`）发布，加入单实例与文件转发。

## 亮点

- 再次启动 MarkSI 时不再创建第二个应用实例，而是恢复并聚焦已运行的主窗口。
- 从文件管理器、命令行或“打开方式”把 Markdown/文本文件交给 MarkSI 时，新进程会把文件路径转发给已运行窗口，然后立即退出。
- 主窗口仍会执行未保存修改确认，不会因为外部打开而丢失编辑内容。
- 单实例通信只使用本机回环地址，并带随机令牌；锁文件位于当前用户的应用数据目录。
- 异常退出留下的锁文件会自动恢复，IPC 失败时回退到正常启动，不阻塞编辑器。
- 支持仅聚焦请求（没有文件参数）和多窗口编辑；转发目标始终是主窗口。

## 下载

- **推荐**：`MarkSI_0.67_x64-setup.exe`，单个安装器内置英文、简体中文和繁体中文界面，并按系统语言选择。
- **企业部署**：`MarkSI_0.67_x64.msi`，安装界面为 `en-US`，应用仍包含三种界面语言。
- **Linux**：`.deb`、`.rpm`、`.AppImage` 和 `.flatpak`。
- 所有安装包均未签名；Windows 可能显示 SmartScreen 提示。

## 校验

Release 附带合并的 `SHA256SUMS.txt` 和 Windows/Linux 两份第三方声明。请先校验下载文件的 SHA-256，再运行安装包。

## English

MarkSI 0.67 (versionCode `67`) adds single-instance handling and file
forwarding. Launching MarkSI again focuses the running main window instead of
opening a second application instance. When the new launch carries a supported
Markdown or text file, the process forwards the path to the running window and
exits before creating a window. The running window still applies the normal
unsaved-change guard.

The handoff uses a tokenized loopback endpoint and a per-user lock file. Stale
locks recover automatically, and IPC failures fall back to a normal launch. The
NSIS `setup.exe` is the recommended installer; the MSI uses an `en-US` installer
UI. Linux packages include deb, rpm, AppImage, and Flatpak. All installers are
unsigned; Windows may show a SmartScreen warning. Verify the attached
`SHA256SUMS.txt` before installation.
